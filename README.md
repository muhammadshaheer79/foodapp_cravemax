## How to run this project locally at your end: -

### Required Software Tools:

**1. Flutter SDK**:
You'll need [FlutterSDK 3.44.5](https://storage.googleapis.com/flutter_infra_release/releases/stable/windows/flutter_windows_3.44.5-stable.zip).

**2. Code Editor**:
Install Visual Studio Code with the Flutter + Dart extension or Android Studio.

**3. Android Toolchain**:
Install Android Studio and set up the Android SDK, SDK Build-Tools, and an Android Emulator.

**4. Platform Dependencies (by OS)**:

- Windows: Install Visual Studio (for Windows desktop apps, optional) or enable developer mode.
- macOS: Install Xcode (required if you want to build iOS apps).
- Linux: Install clang, cmake, ninja-build, and pkg-config for desktop support

Now go to a directory of your liking and:

```bash
# Clone the repository
git clone <this-repository-url>
cd <repository-name>

# Install dependencies
flutter pub get

# Run the app in debug service mode
flutter run
```

### Alternative via IDE:

If you prefer using an interface instead of the terminal, you can pull packages directly through your editor:

**VS Code**: Open the pubspec.yaml file and click the Get Packages icon (download arrow) in the top-right ribbon, or save the file (Ctrl+S / Cmd+S) to trigger it automatically.

**Android Studio / IntelliJ**: Open the pubspec.yaml file and click Pub get in the action bar at the top of the editor.
